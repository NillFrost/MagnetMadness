# Magnet Madness v3.16.1 — classic

Offline HTML5 magnetic arcade bundled into a WebView Android app.

Includes original five-track soundtrack; anti-trap generation, high-DPI Canvas, 120 FPS cap, and optimized mechanics. On game over: up to three larger quest progress cards, ranked by completed missions and percentage gained this run, plus equal-size Revive / Retry actions. Revive uses a three-second TEST advertisement, no ad network.

Independent package ID: com.nillfrost.magnetmadness.classic. Debug build via GitHub Actions and a prerelease APK.
